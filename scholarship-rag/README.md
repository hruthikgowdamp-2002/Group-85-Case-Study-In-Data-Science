# Scholarship RAG Terminal Milestone

This version demonstrates the complete terminal RAG flow: PDF ingestion, tokenization, BM25 and TF-IDF retrieval, and a grounded answer generated by a local Ollama model. It does not include the web interface.

## Install and prepare Ollama

Install Ollama, start it, and download the model:

```bash
ollama serve
ollama pull llama3.2:3b
ollama list
```

If the Ollama desktop application or background service is already running, `ollama serve` may report that port `11434` is already in use. That is normal; continue with the remaining commands.

## Run

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py --reindex
```

Enter questions at `Question >`. The terminal first shows the top three BM25 chunks and top three TF-IDF chunks with their scores. It then sends the best unique retrieved chunk(s) to Ollama and prints the answer and source citations. Type `exit` to stop. On later runs, use `python app.py`.

The default model is `llama3.2:3b`. To use another installed model:

```bash
python app.py --model MODEL_NAME
```

## Verify

```bash
python -m unittest discover -s tests -v
python evaluate.py
```
